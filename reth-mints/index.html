Who actually mints rETH?

Every new rETH mint over 90 days, traced to the contract the transaction entered through. 22 Aug – 19 Nov 2026 (UTC), blocks 25806959–26452577.

In these 90 days, 409 mints created 3,873 rETH against 4,552 ETH. 70.5% of that ETH came straight to the deposit pool from wallets (EOAs) calling deposit() themselves, and the top 10 minters supplied 70.4%. Over the same period, 22,531 rETH was bought out of the tracked DEX pools, about 5.8× the amount minted.

Checks

  • Supply reconciliation (on-chain): rETH totalSupply went from 320,042.2750 to 303,013.8314 (-17028.4436). Minted 3,872.8909 minus burned 20,901.3344 (16998 burn events) = -17028.4436. Gap: -0.000000 rETH.
  • Independent indexer: Routescan's keyless Etherscan-compatible logs API (a separate indexer), same blocks: 409 mint events, 3,872.8909 rETH, 3,911.5177 ETH of new deposits. Gap vs this pipeline: +0 events, +0.000000 rETH, +0.000000 ETH.
  • Public dashboards: rocketscan.io did not resolve on 20 Nov 2026 (no DNS A record), and Rocket Pool's API (api.rocketpool.net/mainnet/payload) publishes no mint or supply history, so neither could be compared. The on-chain supply check above is exact.
  • Contracts: rETH 0xae78736cd615f374d3085123a210448e74fc6393 and deposit pool 0xce15294273cfb9d9b628f4d61636623decdf4fdc resolved through RocketStorage getAddress(keccak256("contract.address"+name)); the deposit pool address was the same at the first and last block of the window, and all 409 mints pair with a deposit-pool event in the same transaction.

Method and caveats

  • A mint is a TokensMinted event on rETH. Each one is followed in the same transaction by either DepositReceived (a user's deposit(), new ETH) or CreditWithdrawn (Saturn 1: a node operator takes existing ETH credit as rETH via withdrawCredit()). Credit withdrawals mint rETH but bring no new ETH in, so they are shown separately.
  • "ETH" means the gross amount in the deposit-pool event; rETH is minted on the amount after the deposit fee (fee total: 2.2758 ETH).
  • Entry point = the transaction's to. A wallet app that sends a plain deposit() from the user's EOA counts as direct; we cannot see which front-end built the transaction.
  • DEX contrast covers Uniswap v3 rETH/WETH pools (all four fee tiers via the factory), the Uniswap v2 pair, every Balancer v2 pool that paid out rETH (Vault Swap events with tokenOut = rETH), and rETH Transfer events out of the Uniswap v4 PoolManager and Balancer v3 Vault (these two count liquidity withdrawals too). Not covered: Curve, other DEXs, OTC and CEX. It is gross outflow: an arbitrage bot that buys on one pool and sells on another counts as a buyer, so it overstates real demand.
  • Labels are fetched automatically; an address with no public tag is shown as unlabelled even if its owner is known elsewhere.
